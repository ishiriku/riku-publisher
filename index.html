Riku Publisher

A personal command-line tool that uploads the developer’s own finished videos to the developer’s own YouTube channels via the YouTube Data API (videos.insert, thumbnails.set, channels.list, videos.list).

  • Users: the developer only (single-owner internal tool; not distributed).
  • Channels: かぞえてみた and the developer’s personal channel いしりく.
  • What it does: upload a finished video, set title / description / thumbnail / scheduled publish time, declare altered or synthetic content where applicable, and confirm the upload finished.
  • What it does not do: read or store other users’ data, comments, or analytics of other channels.
